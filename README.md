## ⚡ Highlights
- **Sub-Second Load Time:** Zero external bulky assets/textures. 100% procedural Canvas 2D vector rendering & synthetic Web Audio SFX.

- **Mobile Touch Native:** Optimized for vertical swipe / drag steering on mobile devices (`touch-action: none`, viewport-fit covered).

## 🕹️ Controls
- **Mobile:** Drag / swipe finger horizontally to steer your ship.
- **Desktop:** Click & drag or use **A / D** / **Arrow Keys**.
- **Objective:** Dodge red hazards, collect cyan energy cores, and trigger the hyper-warp before the 30-second timer expires!

---

## 🛠️ Tech Stack
- **Engine:** Pure HTML5 Canvas / Vanilla JavaScript (ES6+)
- **Audio:** Synthesized Web Audio API (real-time sine/sawtooth wave oscillators)
- **Architecture:** RAF Game Loop with Lerp Smoothing, Particle Emitters & Responsive Layout
